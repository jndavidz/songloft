唱片转动：两档方案 + 转速对照

左边是把封面裁圆转起来，右边是把封面做成一张真黑胶。同一套外观再跑三种转速，最后是裁角损失与成本对照。全部为 CSS 示意，可动。

01

档 A · 最简 低开销

方形封面直接裁成圆盘，外圈加一道细沟槽环，整层匀速旋转。没有盘体、没有高光。

档 B · 黑胶盘 质感

03

裁角损失

内切圆
圆形与方形内切时，圆的直径等于方边。
圆面积占方形 78.5%（π/4），四个角合计被裁掉 21.5%。
四角裁掉 ≈ 21.5% 圆内保留 ≈ 78.5% 每角 ≈ 5.4%

斜线区即被裁掉的部分。封面上的角部文字或边角构图会一并消失，这也是档 B 把封面缩小成中心 label 的原因之一。

04

实现对照

沿用上次评估口径
档 A · 最简档 B · 黑胶盘
改动文件 播放页封面组件单点（presentation 层） 封面组件 + 新增图层 + 播放态联动
代码量 小：组件内加裁剪与旋转 中大：盘体/沟槽/静止高光 + 缓停与淡入
运行开销 低：单层旋转；阴影保持静态 中：多一层合成；高光/阴影不得放进旋转子树
视觉差异 看得出在转，但像「会转的圆图」 盘缘 + 沟槽 + 静止高光，接近真黑胶
风险 裁角损失 21.5%，构图可能被切 启停须跟随 isPlaying，否则 DLNA 假播放会空转
表内数值为定性结论（沿用上次成本评估，本次未重新测量）。性能红线的根因是发光阴影若进入旋转子树且无 RepaintBoundary，会每帧重复高斯模糊。
