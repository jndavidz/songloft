黑胶盘外圈沟槽配色 · 三套方案

盘面几何与 App 实现一致：盘体直径 230、label 占半径一半（直径 50%）、沟槽间距约 2.4px、静态高光固定不随盘转。切换浅色/深色看两套主题下的观感；每套都给「有封面」与「默认 label（无封面兜底）」两种盘心。

主题 seed #415F91 primary（深色 tone80）#A9C7FF 沟槽只靠明度差，不用彩色描边 发光/阴影在盘外，不进旋转子树

深色模式下更融入页面；浅色模式下取值整体提亮约 2 tone，避免在浅背景上变成一块死黑。

为什么好看：盘体带一点靛蓝，和主题 seed 同源又不至于变彩盘；冷蓝亮线像黑胶在冷光下的反射，复古器材味最强。风险与对策：遇到蓝调封面会与盘体融合 —— 所以亮线不超过 5.5%，并在 label 外侧保留 1px 白 14% 描边把封面与盘体切开。

不推荐的做法

  • 高饱和彩色盘体（红/紫/绿）：盘面永远比封面更抢眼，默认 label 也会显得脏，且浅色模式下几乎无法做出“深色唱片”的质感。
  • 发光描边 / 外发光：一是必须放进旋转子树外才能避免每帧重算 blur，二是视觉上廉价，和真唱片的哑光质感冲突。
  • 与封面同色系（从封面取主色染盘体或沟槽）：封面大图会“溶进”盘体，物理边界消失，黑胶的实体感全丢；还要额外算色，收益为负。
  • 纯黑 #000 盘体：沟槽只能靠彩色才看得见，OLED 上盘体还会和背景融为一体，失去轮廓。
  • 浅色模式下用白/米色盘体：与背景几乎同明度，像一张“白纸圆”，必须靠重阴影救，直接违背成本红线。

一套 token，四种组合

discBase盘体 4 停径向渐变（tone 12 → tone 0）
grooveLight / grooveDark沟槽亮/暗描线 alpha，间距 2.4px
labelBase3 停径向渐变；有封面时被封面层完全覆盖
tonearmMetal3 段金属渐变（高光/中调/暗调）
rimGlow外缘 1–2px 导引带，方案 B 用 primary
staticHighlight固定位置弧形高光，不进旋转层

深色/浅色只切换这组 token 的取值，绘制逻辑与几何完全不变；有封面/无封面只切换 label 层，盘体完全不参与——所以兜底盘与有封面盘不会出现“两种界面观感断裂”。兜底盘同样跟随 isPlaying 缓停/起转。
