暂停态 · 旋转 0°（长端垂直）

整根都在盘圆之外：杆身 / 折角段 / 唱头 / 唱针与盘缘最近 1.070R（间隙 0.027d ≈ 7.1px）；唱针尖端在 1.072R（距盘缘 0.028d，262px 下约 7.3px）—— 贴边不压盘。支点 y=0.170d、轴座顶 y=0.122d，均在盘顶 0.110d 之下。

播放态 · 旋转 15.1°（几何反算）

只内旋 15.1°：唱针落到 0.770R（环带 0.54R–1.00R 的正中），杆身整体都在封面圆之外。

① 沟槽 / 星光盘体是近透明白玻璃（无深色盘基），白色亮线 + 极淡暗线撑层次；沟槽上散布 24 颗点状星光，各自错峰明灭；盘体叠加封面主色折射，色相随封面变。星光层在旋转子树之外，不参与旋转。
② 唱臂等宽极淡细杆（同一 strokeWidth 0.0062d，无渐变宽度、关节不收口）+ 极轻投影；暂停 0°（长端垂直、整根在盘外，唱针 1.072R 贴盘缘），播放 15.1°（唱针落环带中线 0.770R），360ms 过渡。轴座整体（含座块/卡扣线/中心圆）最高点 y=0.122d，低于盘顶 0.110d。
③ 两行歌词固定两行窗口；当前行逐字从浅灰渐变为「封面背景色」；唱完一行整行上移一行（非整段滚动）。
④ 背景分两块：播放区从顶部「封面色 + 更显色」向下逐渐变浅，在约 2/3 处抵达控制区底色并保持到尾（接缝无硬边）；控制区浅色主题近白、深色主题为低明度浅灰；取色结果按 song/URL 缓存。
⑤ 盘心取消中心孔，封面直接作为盘心。
⑥⑦⑧歌名/歌手在盘上方，第二行为 歌手 - 《专辑》（缺专辑只显示歌手、缺歌手只显示《专辑》、都没有则显示未知歌手）；下方无两点；播放键无底板；进度条 2px 细线，浅灰轨道 / 深灰已播。
⑨ 封面折射技术路线 A：低清封面一次性烘焙成「模糊 + 半透明」纹理（预烘焙 ui.Image），放进旋转子树并用圆环裁剪（label 外 → 盘缘内）；运行时零模糊，每帧仅一次 drawImageRect + 矩阵变换。色彩分布随转动真实位移。无图时退化为封面主色薄纱（路线 B）。
⑩ 沟槽区材质整圈是半透明白的雾面（亚克力/白玻璃），沟槽只是雾面上的极细亮线 + 淡暗线；不是深色底画白线。
⑪ 唱臂形态（本轮：轴座整体不得高于盘顶 + 等宽细杆）盘径 0.78×方形（R = 0.39d，封面 = 0.54R = 0.211d，环带 0.54R–1.00R 不变）；支点 (0.954d, 0.170d)——水平在盘圆外（离盘心 0.561d ≈ 1.44R），垂直下移到盘顶之下 0.060d；轴座 0.050d×0.096d，座顶 y=0.122d 低于盘顶 0.110d（座块 / 卡扣线 / 中心圆最高点都不过盘顶线）。等宽细杆：直杆 0.355d + 30° 折角 0.070d，两段同一 strokeWidth 0.0062d（= 盘径 0.008，无渐变宽度、关节不收口）；唱头 0.013d×0.028d（约 2 倍杆宽的独立小块）、唱针 0.020d。暂停 0°：长端垂直，整根在盘圆外（最近 1.070R = 间隙 0.027d，唱针尖端 1.072R）；播放 15.1°：唱针落 0.770R 环带正中，杆身不进封面圆。
⑫ 歌词字号设置项「播放页歌词字号」三档（小 15 / 中 17 / 大 20，默认中）；唱盘下两行与单独歌词页共用同一档位，单独歌词页当前行逐字推进、未唱字明显更淡。
⑬ 转速整圈 20s（代码 VinylDisc.period 默认 20s，turns 0→1 即一整圈）；角度按累计值推进——暂停是缓停不倒转，恢复播放与切歌都不回零，因此不会跳角度。
⑭ 版面唱盘与两行歌词整体上移并紧贴（歌词距盘下 6px），空出的纵向余量留在底部控制区上方，不再让歌词贴着进度条；顶部间距按需压缩，不与歌名区挤在一起。
