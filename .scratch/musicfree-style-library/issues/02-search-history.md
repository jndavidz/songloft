# 02: 搜索历史（本地持久化 / 逐条删除 / 点击即搜）

**What to build:** 点击曲库搜索框看到本机搜索历史列表；单条可删（滑动或删除按钮）、支持整体清空；点击任一条立即以该词发起搜索。历史仅存设备本地（不上 server），去重（重复词置顶刷新）、有上限截断（约 20 条）。清空后回到无历史占位态。

**Blocked by:** 01（搜索页骨架）。

**Status:** ready-for-agent

- [ ] 搜索一次后重进搜索页可见该历史词
- [ ] 重复搜索同一词历史只留一条且置顶
- [ ] 单条删除与整体清空均生效且持久（重启 app 不复活）
- [ ] 超上限时最旧词被挤出
- [ ] 点击历史词直接触发搜索
- [ ] 历史持久化读写有 Dart 单测（增删去重上限）
